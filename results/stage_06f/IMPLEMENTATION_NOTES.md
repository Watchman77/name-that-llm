# Stage 06F no-fit diagnostic implementation

Preparation only; these notes do not assert an executed result. The executable is `scripts/stage06f_pair_diagnostics.py`; the prospective plan is `plans/STAGE_06F_PAIR_DIAGNOSTICS.md`. Dependencies are Python standard library, NumPy and pandas. There are no estimator/model imports, fitting, learned inference, grouping operations, new corrective predictions, parameter searches or external calls.

`run_diagnostics(input_root, output_root, freeze_path=None)` is callable for contract fixtures. Production `__main__` requires `NTL_STAGE06F_FREEZE`; paths default to `NTL_STAGE06F_INPUT=/kaggle/input` and `NTL_STAGE06F_OUTPUT=/kaggle/working/stage06f_diagnostics`. The source/plan freeze requires exact `diagnostic_source_sha256`, `plan_sha256`, `input_version_ids=[170484,359514801]`, `accelerator="none"`, `internet_enabled=false`; `plan_path` can explicitly bind the materialized plan file. Production output must be absent or empty. Every failure writes a retained terminal failure status; no complete marker is printed on failure.

Seven immutable files are read: official `train.csv`, E `ensemble_arrays.npz`, `ensemble_result.json`, `output_manifest.json`, and raw-control confusion CSVs for contexts 1/3/6. SHA256 hashes are fixed in the script before execution. The consumed ensemble cache contains all five static member probabilities, plain/centered DeBERTa captured log probabilities, coordinates/fold maps, raw evidence and posterior, so no other numeric cache is needed. The source result must bind the known canonical and static cache hashes and the fixed seven weights. Exact original-order evidence replay, argmax, full confusion and aggregate source counts gate all diagnosis. Source softmax replay tolerance is absolute `2e-15`; pair-contribution decomposition tolerance is `1e-12`. Contributions are descriptive cached evidence arithmetic, never a new model readout.

## Output schema

- `source_gate.json`: immutable input/cache provenance, exact coordinate/fold/evidence/prediction/confusion gates, source scores and numerical tolerances.
- `pair_result.json`: source-only scores; fixed pair counts; unique-passage and repeated-context overlap; conditional prompt-bootstrap intervals; component disagreement summaries; scope, runtime and limitations. No new candidate score or acceptance decision.
- `pair_diagnostics.npz`: numeric/Unicode only, exact readback. Coordinates `ids/classes/y/prompt_ids/fold/scenarios`; pair indices; unchanged `source_prediction_raw_control`; `pair_true_mask`; outcome `(3,N)` codes `0=nonpair not false entry,1=pair correct,2=pair cross,3=pair predicted outside pair,4=nonpair falsely predicted pair`; signed and truth-oriented margins; uncalibrated conditional-A/global/pair masses; stable-order top-two labels/scope; seven weighted pair contributions `(3,N,7)` and neutral-aware preferences; centered active mask; numeric text features `(N,12)` and feature-name strings. For true non-pair rows, truth-oriented margins are zero placeholders and are never interpreted as true-label evidence. Per-member pair preference `+1/-1/0` means 3.7/3.8/neutral; it is a within-pair preference, not the member's global top-one prediction.
- `pair_rows.csv`: the 300 true-pair rows plus other-class false entries in each context, with IDs/labels/coordinates, scalar margins/masses and disagreement counters; no passage text. `members_supporting_true=0` on nonpair rows is an inactive placeholder.
- `confidence_bins.csv`: fixed margin/uncalibrated score bins, counts and true-pair correct/cross/other partitions. `conditional_pair_max` is pair-preference strength in `[.5,1]`; it is not conditional correctness probability. Last bin includes its upper endpoint. Infinite upper margin endpoint is empty/None.
- `component_contributions.csv`: seven member truth-oriented pair-margin summaries and true/other/neutral preference counts, partitioned by actual raw-control pair outcome and context. Inactive centered entries are exactly neutral.
- `other_class_false_entries.csv`, `folds.csv`, `prompts.csv`: unchanged prediction diagnostics, context explicit, including exact top-two scope that never modifies a prediction.
- `text_features.csv`: numeric shape summaries by actual outcome/context only; no causal interpretation or selected corrective feature.
- `output_manifest.json`: byte sizes and hashes for outputs except mutable status and itself. `status.json`: terminal observed status.

Pair overlap populations are explicit: 300 true-pair passages for correct/cross/other, and 2,399 true nonpair passages for false entries. Thus zero-context counts refer to the declared population. The 150 prompts are jointly resampled across contexts in 3,000 bootstrap draws with seed `20261018`. No predictions, fits or groups are resampled/recreated. Intervals are conditional descriptive uncertainty for the fixed reused-development evidence.

Compact source gate, component/bin/false-entry/fold/text summary CSVs, result and manifest are printed with `STAGE06F_` markers for audit extraction. Row/prompt tables and numeric arrays remain on the immutable Kaggle output unless explicitly retrieved. Binary output must not be described as independently audited on another machine solely because its manifest is available.
